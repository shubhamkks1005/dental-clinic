## Commands (run from repo root, Node 26 and pnpm 12)
- pnpm dev - builds web once, then runs Vite (5173, proxies /api and /hooks) + wrangler dev (8787) together
- pnpm build - Vite build to apps/web/dist + Worker bundle dry-run to apps/worker/dist (one Worker with static assets)
- pnpm check - typecheck (all packages) + eslint + prettier --check + vitest (all packages)
- pnpm db:generate - drizzle-kit writes a new SQL migration from the schema
- pnpm db:lock - record checksums of new migrations (required before commit; test checks it)
- pnpm db:migrate - apply packages/db/migrations to the LOCAL D1
- pnpm deploy:staging - build, then `wrangler deploy --env staging` (needs CLOUDFLARE_API_TOKEN in the terminal + real IDs)
- pnpm spike:d1 - spike 0.6.3 against the real throwaway D1 (needs the token in the terminal)
- pnpm --filter @clinic/worker wr <args> - wrangler with repo-local config/logs (no files in the home folder)
- pnpm format - prettier --write (never touches *.md or .cursor)

## packages/db (tables: name - purpose - key columns)
All tables also have the standard columns (id, created_at, updated_at, created_by, updated_by, deleted_at, version).
- users - staff logins (src/schema/users.ts) - email (unique, lowercase), name, role (doctor|receptionist|developer), status (active|disabled), google_sub (unique, bound on first Google sign-in), last_login_at
- staff_sessions - staff sign-in sessions (src/schema/staff-sessions.ts) - user_id (FK users, indexed), token_hash (unique, SHA-256 of the cookie token), expires_at (12 h absolute), last_seen_at (idle check), revoked_at, user_agent
- settings - doctor-editable settings, versioned + audited (src/schema/settings.ts) - key (unique), value_json (valid JSON)
- counters - every gap-free number (src/schema/counters.ts) - name (patient_code|prescription|bill|receipt|refund|certificate), period ('all' or '2026-27'), value >= 0; unique (name, period)
- audit_log - append-only change history (src/schema/audit-log.ts) - action (create|update|delete|restore), table_name, row_id, before_json, after_json, request_id; who = created_by
- access_log - sign-ins, failures, staff changes, views, exports (src/schema/access-log.ts) - action (login|login_failed|login_denied|logout|staff_change|view|export), resource, resource_id, request_id, detail (reason, masked email); who = created_by ('anonymous' for failed sign-ins)
- files - R2 file metadata (src/schema/files.ts) - patient_id (no FK until patients exist), r2_key (unique), kind, mime, bytes > 0, sha256
- migrations/0000_base_tables.sql - creates the 6 tables

## Gotchas (things that surprised us)
- Your terminal's default Node is nvm v16; use `nvm use system` (Homebrew Node 26) or `nvm install` before pnpm.
- TypeScript is pinned to 6.0 because typescript-eslint 8.x does not support TypeScript 7 yet.
- pnpm blocks dependency build scripts; only esbuild and workerd are allowed (pnpm-workspace.yaml).
- Remote D1 in `wrangler dev` (spike) needs a workers.dev subdomain registered on the account first.
- All wrangler commands run via the `wr` script so config and logs stay in apps/worker/.wrangler. No `wrangler login` on the dev Mac: CLOUDFLARE_API_TOKEN is typed with `read -s` per terminal session.
- pnpm 12 writes its own version into pnpm-lock.yaml (packageManager field). After changing packageManager, run `pnpm install` and commit the lockfile, or CI's frozen install fails.
- CSS order matters: main.tsx must import base.css/ui.css before App, or base rules (like .btn display) override screen rules. A component's visibility rule lives in one CSS file only (e.g. .shell-nav in nav.css).
- Vite build prints a harmless "use client" warning from react-router (no server rendering here).
